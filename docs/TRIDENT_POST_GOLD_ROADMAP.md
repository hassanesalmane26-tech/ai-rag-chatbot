## A. Immutable product vision

TRIDENT is not a chatbot. TRIDENT is an AI Operating System centered around an
Intelligent Workspace. The Workspace is the hero.

Nova is one intelligent module inside the Workspace alongside:

- Knowledge
- Memory
- Files
- Artifacts
- Activity
- Search / TRIDENT Command
- Settings

Later evolution may add, where justified:

- Projects
- Agents
- Automations
- Deep Research
- Advanced orchestration
- Expanded memory
- Advanced system intelligence

The TRIDENT Bible, Rules, Architecture, and Roadmap remain the functional and
architectural source of truth.

The founder-approved futuristic TRIDENT Workspace mockup is the **primary visual
target** for the next interface phase. It is a visual target, not permission to
invent capabilities. Never show fake metrics, agents, model counts, memory
capacity, status, or non-functional buttons merely to imitate the mockup.

## C. Responsive requirement

The definitive interface must be deliberately adapted for mobile phones,
tablets, laptops, standard desktops, and large desktops. Do not mechanically
shrink a three-column desktop layout.

Mobile must preserve the same product identity through compact navigation,
bottom navigation where appropriate, drawers, sheets, selectors, contextual
panels, touch-friendly controls, safe-area support, no clipping, and no
inaccessible content.

Accessibility, reduced-motion support, keyboard navigation where relevant, and
performance are release requirements.
